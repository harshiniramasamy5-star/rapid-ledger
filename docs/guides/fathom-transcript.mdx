## Overview

The full pipeline from meeting recording to compliance archive:

```
Meeting (Zoom / Teams / Google Meet)
  ↓
Fathom Video (fathom.video) — AI meeting recorder
  ↓ export transcript .txt
RAPID Ledger — paste into Fathom Transcript card
  ↓ creates linked TRANSCRIPT document
Submit → Approve
  ↓
Notion DB — permanent compliance archive
```

## Step 1: Export from Fathom Video

1. Open your meeting in Fathom Video (fathom.video)
2. Go to **Transcript** tab
3. Copy the full transcript text

## Step 2: Attach in RAPID Ledger

1. Open any draft RAPID document
2. Find the **🎙 Fathom Transcript** card
3. Paste the transcript text
4. Click **📎 Attach Transcript**

This creates a `TRANSCRIPT`-type child document linked to your RAPID doc via `parentDocumentId`.

## Step 3: Via API

### Create TRANSCRIPT document

```bash
curl -X POST https://rapid-ledger-production.up.railway.app/api/documents \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Transcript — Q3 Strategy Meeting",
    "decisionSummary": "Meeting summary...",
    "riskLevel": "LOW",
    "documentType": "TRANSCRIPT",
    "parentDocumentId": "<rapid_doc_id>"
  }'
```

### Attach transcript content

```bash
curl -X POST https://rapid-ledger-production.up.railway.app/api/documents/<id>/transcript \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "Full transcript text here...",
    "mediaUrl": "https://fathom.video/recording/abc123"
  }'
```

### Export as .txt

```bash
curl https://rapid-ledger-production.up.railway.app/api/documents/<id>/transcript/export \
  -H "Authorization: Bearer <token>" \
  -o transcript.txt
```
