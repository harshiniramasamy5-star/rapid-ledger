title: Audit Log
description: Immutable record of every action in RAPID Ledger
---

## Overview

Every action in RAPID Ledger writes an immutable `AuditLog` entry. Entries are never deleted or modified.

## Query the Audit Log

```bash
curl "https://rapid-ledger-production.up.railway.app/api/audit/logs" \
  -H "Authorization: Bearer <token>"
```

With filters:

```bash
curl "https://rapid-ledger-production.up.railway.app/api/audit/logs?action=document_approved&limit=20" \
  -H "Authorization: Bearer <token>"
```

## All Audit Actions

| Action | Trigger |
|--------|---------|
| `login` | Successful login |
| `login_failed` | Failed login attempt |
| `user_created` | New user registered |
| `user_updated` | User profile changed |
| `org_created` | Organisation created |
| `invite_sent` | Invite email dispatched |
| `invite_accepted` | User joined org |
| `totp_enabled` | 2FA activated |
| `totp_disabled` | 2FA deactivated |
| `document_created` | Document created |
| `document_submitted` | Submitted for review |
| `document_approved` | Approved by all agree roles |
| `document_rejected` | Rejected by approver |
| `document_needs_changes` | Changes requested |
| `document_finalized` | Locked to ledger |
| `document_versioned` | New version created |
| `document_recommended` | Recommendation submitted |
| `document_input_provided` | Input notes added |
| `execution_complete` | Performer marked done |
| `evidence_added` | Evidence or transcript attached |
| `transcript_exported` | Transcript .txt downloaded |
| `ledger_entry_created` | Immutable ledger entry written |
| `notion_synced` | Doc pushed to Notion |
| `webhook_failed` | Integration handler error |
| `webhook_retried` | Manual resync triggered |
| `sync_failed` | Notion sync failed |
| `sync_recovered` | Sync recovered after failure |
| `email_verification_sent` | Verification email sent |
| `email_verified` | Email address confirmed |

```json
{
  "id": "log_abc123",
  "userId": "user_admin_001",
  "action": "document_approved",
  "entityType": "RapidDocument",
  "entityId": "doc_xyz",
  "documentId": "doc_xyz",
  "orgId": "org_abc",
  "details": "{"comment": "Approved", "allApproved": true}",
  "createdAt": "2026-06-05T19:12:42.874Z"
}
```
