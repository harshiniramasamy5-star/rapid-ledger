## System Roles

RAPID Ledger has two role layers: **system roles** (user-level) and **RAPID roles** (document-level).

### System Roles

| Role | Description |
|------|-------------|
| `admin` | Full access — create orgs, finalize docs, manage users |
| `creator` | Creates and submits documents |
| `approver` | Agrees or rejects documents in awaiting_agreement |
| `recommender` | Provides recommendations on documents |
| `performer` | Executes approved decisions |
| `viewer` | Read-only access, can provide input notes |

### RAPID Document Roles

Assigned per-document via `POST /documents/:id/roles`:

| RAPID Role | Maps To | Permission |
|------------|---------|------------|
| `recommend` | Recommender | Submit recommendation notes |
| `agree` | Approver | Approve / reject / request changes |
| `perform` | Performer | Mark execution complete |
| `input` | Viewer | Submit input notes |
| `decide` | Admin | Final authority, finalize |
