## Status State Machine

```
draft
  ↓ submit
review / awaiting_agreement
  ↓ approve (all agree roles)
approved  ←──────── WebhookDispatcher fires here
  ↓                  └─ NotionSyncService syncs to Notion
finalized (admin)
  ↓ perform
execution_complete
  ↓ version (creates v2)
draft (new version)
```

Rejection paths:
```
awaiting_agreement → rejected
awaiting_agreement → needs_changes → draft
```

## Status Reference

| Status | Description |
|--------|-------------|
| `draft` | Initial state. Creator can edit. |
| `review` | Submitted. Awaiting agree roles. |
| `awaiting_agreement` | One or more Agree roles must approve. |
| `approved` | All approvals received. Notion sync triggered. |
| `needs_changes` | Approver requested revisions. Back to creator. |
| `rejected` | Document rejected. Terminal state. |
| `finalized` | Admin locked the document. Added to Ledger. |
| `execution_complete` | Performer marked execution done. |

## Document Types

| Type | Purpose |
|------|---------|
| `RAPID` | Core decision document — full lifecycle |
| `PORTAL` | Cross-org or public-facing document |
| `TRANSCRIPT` | Meeting transcript linked to a RAPID doc |
