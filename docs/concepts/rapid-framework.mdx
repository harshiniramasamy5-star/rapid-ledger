## Overview

RAPID is a decision-making framework that eliminates ambiguity by assigning exactly one person to each role for every decision. No shared ownership, no unclear accountability.

```
R — Recommend   → proposes the decision
A — Agree       → high-risk sign-off (optional, for critical decisions)
P — Perform     → executes after approval
I — Input       → provides expert context (no vote)
D — Decide      → final authority (always the admin)
```

## Role Assignment

Each role is assigned per-document via the `RoleAssignment` table. One user can hold one role per document. The Decide role is always the document's admin owner.

```json
{
  "roleType": "recommend",
  "userId": "user_recommender_001",
  "documentId": "doc_abc123"
}
```

## Document Flow

```
Draft
  → [Recommender submits notes]
  → [Input providers add context]
  → Submitted for Review
  → [Agree role approves — if assigned]
  → Approved
  → [WebhookDispatcher → Notion sync]
  → [Performer executes]
  → Execution Complete
  → [Admin finalizes]
  → Finalized (immutable ledger entry)
```

## Risk Levels

| Level | Requires Agree Role |
|-------|-------------------|
| LOW | No |
| MEDIUM | No |
| HIGH | Yes |
| CRITICAL | Yes |

When risk is HIGH or CRITICAL and an Agree role is assigned, the document enters `awaiting_agreement` status before it can be approved.
