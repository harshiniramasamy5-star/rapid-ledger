title: Quickstart
description: Run RAPID Ledger locally in under 5 minutes
---

## Prerequisites

- Node.js 18+
- Bun runtime (`curl -fsSL https://bun.sh/install | bash`)
- PostgreSQL (or use Railway for hosted DB)

## 1. Clone and Install

```bash
git clone https://github.com/harshiniramasamy5-star/rapid-ledger.git
cd rapid-ledger
npm install
```

## 2. Environment Variables

Create `apps/api/.env`:

```bash
DATABASE_URL="postgresql://user:password@localhost:5432/rapidledger"
JWT_SECRET="your-secret-key-min-32-chars"
REFRESH_TOKEN_SECRET="another-secret-key"
NOTION_API_KEY="ntn_..."          # optional
NOTION_DATABASE_ID="..."          # optional
```

Create `apps/web/.env.local`:

```bash
NEXT_PUBLIC_API_URL="http://localhost:3001/api"
```

## 3. Migrate and Seed

```bash
cd apps/api
npx prisma migrate deploy --schema=../../prisma/schema.prisma
npm run db:seed   # run from repo root
```

## 4. Start Dev Servers

```bash
# Terminal 1 — API (Bun + Elysia)
cd apps/api && bun src/index.ts

# Terminal 2 — Frontend (Next.js 15)
cd apps/web && npm run dev
```

| Service | URL |
|---------|-----|
| Frontend | http://localhost:3000 |
| API | http://localhost:3001 |

## 5. First API Call

```bash
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@rapid.com","password":"password123"}'
```

Response:
```json
{
  "token": "eyJ...",
  "user": { "id": "...", "email": "admin@rapid.com", "role": "admin" }
}
```

## 6. Run Tests

```bash
cd apps/api && npx vitest run        # 80 Vitest tests
cd apps/web && npx jest              # 9 Jest tests
cd apps/web && npx playwright test   # 12 E2E tests
```
