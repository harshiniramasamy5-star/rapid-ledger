## POST /integrations/notion/connect

Check Notion configuration status.

```bash
curl -X POST /api/integrations/notion/connect \
  -H "Authorization: Bearer <token>"
```

Response:
```json
{
  "connected": true,
  "notionDatabaseId": "3757c231...",
  "message": "Notion integration is active."
}
```

## POST /integrations/notion/sync/:documentId

Manually sync an approved document to Notion.

## GET /integrations/notion/status/:documentId

```json
{
  "syncStatus": "SYNCED",
  "notionPageId": "3767c231-...",
  "syncedAt": "2026-06-05T19:12:42.874Z",
  "notionConfigured": true
}
```

## POST /integrations/notion/resync/:documentId

Force resync — resets to PENDING and retries. Logs `webhook_retried`.
