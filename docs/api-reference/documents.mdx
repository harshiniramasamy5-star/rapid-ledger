title: Documents
description: Create, update, submit, and manage RAPID documents
---

## POST /documents

Create a document.

```bash
curl -X POST /api/documents \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Migrate to PostgreSQL",
    "decisionSummary": "Switch from SQLite to PostgreSQL for production.",
    "riskLevel": "HIGH",
    "documentType": "RAPID"
  }'
```

Response `201`:
```json
{
  "document": {
    "id": "doc_abc",
    "documentCode": "RAPID-001",
    "version": 1,
    "status": "draft",
    "documentType": "RAPID"
  }
}
```

## GET /documents

List all documents visible to the authenticated user.

## GET /documents/:id

Get full document detail including roles, approvals, evidence.

## PATCH /documents/:id

Update document fields (creator only, draft/needs_changes status).

## POST /documents/:id/submit

Submit document for approval.

## POST /documents/:id/recommend

```json
{ "notes": "I recommend proceeding based on..." }
```

## POST /documents/:id/input

```json
{ "notes": "From a security perspective..." }
```

## POST /documents/:id/approve

Approver agrees.

```json
{ "comment": "Approved — meets all compliance requirements." }
```

## POST /documents/:id/reject

```json
{ "comment": "Rejected — missing risk assessment." }
```

## POST /documents/:id/needs-changes

```json
{ "comment": "Please add alternatives considered section." }
```

## POST /documents/:id/finalize

Admin only. Locks document and writes to Ledger.

## POST /documents/:id/execution-complete

Performer marks execution done.

```json
{ "notes": "Migration completed successfully on 2026-06-05." }
```

## POST /documents/:id/version

Creates a new draft version (v2, v3...).

## GET /documents/:id/export-pdf

Downloads a compliance-ready PDF.
