---
title: Authentication
description: Login, register, refresh tokens, email verification
---

Base URL: `https://rapid-ledger-production.up.railway.app/api`

## POST /auth/register

Create a new account.

```bash
curl -X POST /api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Alice Admin",
    "email": "alice@acme.com",
    "password": "securepassword123"
  }'
```

Response `201`:
```json
{ "message": "Registration successful. Please verify your email." }
```

## POST /auth/login

```bash
curl -X POST /api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@rapid.com", "password": "password123"}'
```

Response `200`:
```json
{
  "token": "eyJ...",
  "user": {
    "id": "user_admin_001",
    "name": "Alice Admin",
    "email": "admin@rapid.com",
    "role": "admin"
  }
}
```

Error `403` — email not verified:
```json
{ "error": { "code": "EMAIL_NOT_VERIFIED", "message": "Please verify your email." } }
```

## POST /auth/refresh

```bash
curl -X POST /api/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "..."}'
```

## GET /auth/me

```bash
curl /api/auth/me -H "Authorization: Bearer <token>"
```

## GET /auth/verify-email?token=

Verifies email address from link in verification email.

## POST /auth/logout

```bash
curl -X POST /api/auth/logout -H "Authorization: Bearer <token>"
```
