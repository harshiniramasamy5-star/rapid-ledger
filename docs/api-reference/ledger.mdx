## GET /ledger

Returns all finalized ledger entries visible to the authenticated user.

```json
[
  {
    "id": "ledger_abc",
    "documentId": "doc_xyz",
    "documentCode": "RAPID-001",
    "version": 1,
    "finalizedAt": "2026-06-05T20:00:00Z",
    "hash": "sha256_..."
  }
]
```

Each entry is immutable. Finalization triggers `document_finalized` and `ledger_entry_created` audit logs.
