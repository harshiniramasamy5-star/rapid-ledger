---
title: Organizations
description: Org management, invites, members
---

## POST /orgs

Create an organisation (admin only).

```json
{ "name": "Acme Corp", "domain": "acme.com" }
```

## GET /orgs/:id

Get org details and member count.

## GET /orgs/:id/members

List all members of an org.

## POST /orgs/:id/invite

Send invite (admin only).

```json
{ "email": "newuser@acme.com", "role": "creator" }
```

Returns invite token valid for 7 days.

## POST /orgs/join/:token

Accept invite. User is added to org with assigned role. Logs `invite_accepted`.
