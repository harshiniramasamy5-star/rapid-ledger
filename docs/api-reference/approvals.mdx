---
title: Approvals
description: Approve, reject, and manage document approvals
---

## Approve a document

    POST /api/documents/:id/approve
    Authorization: Bearer token

    { "notes": "Approved after review" }

## Reject a document

    POST /api/documents/:id/reject

    { "notes": "Needs more context" }

## Request changes

    POST /api/documents/:id/request-changes

## Get my approvals

    GET /api/approvals/my
    Authorization: Bearer token
