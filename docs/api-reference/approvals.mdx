---
title: Approvals
description: Approval queue management
---

## GET /approvals/pending

Returns all documents awaiting the authenticated user's approval.

```bash
curl /api/approvals/pending -H "Authorization: Bearer <approver_token>"
```

## GET /approvals/my

Returns all approval records for the authenticated user.

## POST /approvals/:documentId/approve

```bash
curl -X POST /api/approvals/<docId>/approve \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"comment": "Approved."}'
```

When all assigned Agree roles approve, document transitions to `approved` and `document.approved` webhook fires.
